# Selenium JavaScript

For each file `spec/features/*`, there is a corresponding
`tests-with-selenium-javascript/*` test file — the original suite that
every other suite (Playwright JS, and the TypeScript and Python ports of
both) is a mechanical port of.

See [`testing.md`](testing.md) for the full shared contract, architecture
rules, and how to add a new feature's tests across all six suites — this
file is kept only as the historical one-line instruction the suite was
originally built from.
