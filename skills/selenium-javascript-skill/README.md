# Selenium JavaScript Skill

This repo is a Claude Code [Skill](https://www.selenium.dev/) reference for
writing [Selenium](https://www.selenium.dev/) WebDriver browser-automation
code and tests in JavaScript. It is not a runnable demo itself — it is
documentation that teaches an AI coding agent (or a human) how to locate
elements, perform actions, wait correctly, and write real assertions using
the `selenium-webdriver` npm package.

The actual content lives in [SKILL.md](SKILL.md).
